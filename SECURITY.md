# Reporting a security vulnerability

Please report suspected vulnerabilities privately to **contact@vibesafebuilder.com**. Do not put exploit details, credentials, or customer code in public issues.

Include the affected repository and version or commit, a minimal reproduction using synthetic data, the expected and actual behavior, and the potential impact. Redact tokens and personal information.

For ordinary bugs and feature requests, use GitHub issues. This reporting route does not promise a response deadline or a bounty.
