Common questions

Is a template really free?

Yes. Opening a template doesn't run the AI, so it costs zero tokens on any plan. Changes you ask the AI to make afterwards are normal builds, and every new account's first AI build is free.

Where does a template save its data?

Templates that remember things store them in the visitor's own browser, so each person sees only their own data. If you need data shared between people, like bookings sent to you, ask the builder for it and it can add a real backend.

Can I download a template and host it myself?

Yes. Each template is a single HTML file with no build step, so you can download it and host it anywhere, or publish it to a shareable link from the builder. The deploy guide covers the options.

Are templates security-scanned?

Yes. A template becomes version 1 of your project, and publishing it runs the same security scan as any AI build. None of the templates load outside scripts or contain secrets. See how VibeSafe Builder keeps apps safe.
