01Getting started

What is VibeSafe Builder?

An AI app builder. You describe an app in plain English and it writes a working one. Every build shows its cost before it runs, every change is a version you can roll back, and every build is security-scanned before you can publish it. See how it works.

Do I need to know how to code?

No. You describe what you want and ask for changes in plain English. The full code is always visible if you want to read it, but you never have to touch it.

Is there a free trial?

Yes. Sign up and your first build is free, with no API key and no card. It runs on a lighter AI model (Claude Sonnet 5) rather than the Claude Opus 5 model both plans use, so expect a less polished result. You can also try the interactive demo with no account at all.

Do I need an account?

Yes. Every account signs up first, including if you bring your own API key. You can sign up with an email and password, Google, or GitHub. Signing in with GitHub does not give the builder access to your repositories.

02Pricing and billing

How much does it cost?

Two plans. Bring your own Anthropic API key for a $0 platform fee, and Anthropic bills you directly at their standard rates with no markup. Or take the Managed plan at $15/month, with no API key needed and $10/month of usage included. A typical single-file build costs about $0.05 to $0.20 on your own key. Full details are on the pricing page.

Do failed generations cost me anything?

Failed generations never count toward your build spend. The meter shows them separately as “failed (not counted)”. On the Managed plan, a failed attempt still draws from your $10 of included usage, because it is real cost to us, but you are never charged extra.

What happens if I go over the Managed budget?

Generation pauses until your next billing cycle. You are never charged overage. Switch to your own API key in Settings to keep going straight away.

Which AI model does it use?

Builds on either plan use Claude Opus 5. The free first build uses Claude Sonnet 5, a lighter model. Every mode (Auto, Build, Debug and Review) uses the same model as your plan.

03Building apps

What can I build with it?

Prototypes, internal tools, calculators, trackers, dashboards, landing pages and small single-purpose apps. Start from a sentence or from one of 16 free templates. When an app needs more, it can share data between visitors, give visitors their own accounts, accept file uploads, collect contact or waitlist forms, and sell products through your own Stripe account. For bigger ideas, start a multi-file React project.

What can't it do yet?

It cannot run your own server-side code beyond the built-in data backend, so business logic that must stay hidden from users is not a fit yet. There are no team accounts or shared projects, published apps cannot use a custom domain yet (deploy a React project to your own Vercel account for that), and it does not build native mobile apps. The comparison page says when to pick something else.

Can I undo a change?

Yes. Every successful build is saved as a version with a line-by-line diff against the one before. Open the Versions tab and click Restore on any earlier version. Later versions stay in the list.

What if the AI keeps failing to fix the same problem?

If you ask for a fix twice in a row, the builder tells the AI to stop repeating itself and re-diagnose from scratch. You can also switch the Agent menu to Debug to focus on one problem, or Review for a written report that changes no code.

Can I make sure a later change doesn't break something important?

Yes. In the Refine panel, Non-negotiables lets you write what the app is for and up to 12 rules that must stay true. The AI reads them before every build and tells you when a request would break one.

Can I use my own colours, logo and images?

Yes. Brand style sets the palette the AI builds with, and Brand assets takes your own logo, hero image or background (PNG, JPEG, WebP or GIF). Images are resized in your browser, which strips location data from photos. SVG is refused because it can carry scripts.

04Features inside your app

Can my app take payments?

Yes, through Stripe Payment Links. You create a link in your own Stripe account, paste it into Monetisation, and the AI builds the buy button. Buyers pay on Stripe's own checkout page and the money goes straight to you. We never handle the payment and no secret key is needed. Subscriptions and server-side checkout are not available yet.

Can my app collect contact forms or a waitlist?

Yes. The Forms tab creates contact and waitlist forms with a private inbox, CSV export, optional email notifications to you, and an optional confirmation email to the person who submitted. Receiving submissions uses no AI credits. See Forms in the user guide for limits.

Can my app have user accounts and shared data?

Yes. Ask for it and the app uses a built-in backend: shared data that every visitor sees, sign-up and log-in for your app’s own visitors with data private to each of them, and file uploads (PNG, JPEG, GIF, WebP or PDF, up to 2MB each). These work once the app is published. More in the user guide.

05Your code, data and security

Who owns the code?

You do. The full code is always visible. Download a single-file app as one HTML file you can host anywhere, or push a React project to a GitHub repository you own. There is no proprietary format and no export step.

Is my API key safe?

Your Anthropic key is stored only in your browser and sent with each build so it can reach Anthropic. It is never stored on our servers. Published apps are checked for leaked keys before they go live. See the security page.

Where is my project saved?

In your browser. Your current project, its chat and up to 20 versions are saved automatically, and earlier projects are kept in My Apps. Clearing browser data or switching devices loses them, so download, push to GitHub or publish anything you want to keep elsewhere.

What does the security scan check?

Every build is checked for common AI-coding mistakes such as hardcoded API keys and secrets, eval() and other dynamic code execution, passwords saved in browser storage, and insecure requests. Publishing re-runs the check on our server and is blocked on a critical finding. Launch Check also opens your app in a real browser to catch crashes, console errors, failed loads and mobile layout breaks. See exactly what gets checked.

06Publishing

How do I share or publish my app?

Click Publish in the Preview tab for a public link anyone can open, install to their home screen and use offline. Republish updates the same link. A React project can also be pushed to GitHub or deployed to your own Vercel account, with your own domain. The deployment guide covers every option.

Can I report an app published with VibeSafe Builder?

Yes. Every published app has a small Report link, or use the report page. Reports go to a review queue, and apps that break the rules are taken offline.

07About

Is this the same as VibeSafe at vibesafe.info?

No. VibeSafe is a separate code security scanner from the same company, SG Digital Ventures LLC. VibeSafe Builder is the app builder; it has a security scan built in, but generating apps is what it does.
